## 模块二：实战案例一：注册漏斗 $2 	imes 2$ 全因子实验设计

```text
2x2 全因子实验矩阵 (Full Factorial Design):
                       按钮颜色 (Color)
                 红色 (Red)         蓝色 (Blue)
              ┌─────────────────┬─────────────────┐
  顶部 (Top)  │   Control (T0)  │  Treatment (T1) │
              │   红色 + 顶部   │   蓝色 + 顶部   │
按钮位置      ├─────────────────┼─────────────────┤
(Position)    │  Treatment (T2) │  Treatment (T3) │
  底部 (Bottom)│  红色 + 底部   │   蓝色 + 底部   │
              └─────────────────┴─────────────────┘
```

- **交互效应估计量**：
  $$\hat{eta}_3 = (T_3 - T_1) - (T_2 - T_0) = T_3 - T_2 - T_1 + T_0$$
- **触发曝光定义（防稀释机制）**：底部按钮采用 Viewport Intersection Observer，仅在滚动进入可视视口时记录有效曝光。

## 模块三：实战案例二：电商商详页 (PDP) 改版（CTR 涨，CVR 平）转化归因

```text
电商转化漏斗分解与流量稀释效应:
【全盘列表曝光 Impression】 (100,000)
       │
       ▼  CTR (Control: 5.0% ➔ Treatment: 5.6%, 相对 +12%)
【进入商详页 PDP Pageviews】 (Control: 5,000 ➔ Treatment: 5,600)
       │
       ▼  CVR (Control: 10.0% ➔ Treatment: 10.0%, 相对 +0%)
【最终下单成交 Purchases】 (Control: 500 ➔ Treatment: 560, 净增 +60 单! 全盘净增长 +12%!)
```

1. **全盘无条件成交净增（CTCVR 增长）**：
   $$	ext{CTCVR} = rac{	ext{总购买订单数}}{	ext{总展示曝光数}} = 	ext{CTR} 	imes 	ext{CVR}$$
   当 $	ext{CTR}$ 提升 $+12\%$ 且条件转化率 $	ext{CVR}$ 保持不变（$10\% 	o 10\%$）时，**单次曝光带来的全盘总成交订单量实际上净增长了 $+12\%$**！
2. **流量稀释效应（Traffic Dilution / Selection Effect）**：
   改版吸纳了大量低意向边缘访客（Marginal Users）。在分母被稀释的情况下仍维持 CVR 平稳，证明商详页承接能力强劲。

## 模块四：极小样本高价值分层（Small-Sample Tier）统计推断方案

大客户 / 黑金 VIP 层的样本量极小（如 $N pprox 100$），标准双样本 $t$ 检验统计功效 $	ext{Power} < 20\%$，置信区间宽达 $[-18\%, +22\%]$（$p = 0.45$）。

```text
极小样本分层三大科学推断方案:
┌────────────────────────────────────────────────────────────────────────┐
│ 方案 1: 贝叶斯分层模型与部分池化 (Empirical Bayes Partial Pooling) ★推荐│
│ • 收缩估计公式: θ_small_shrunk = B · μ_grand + (1 - B) · Y_small       │
│ • 跨层"借力": 小样本方差大时自动向大盘均值收缩，消除极端随机噪点      │
├────────────────────────────────────────────────────────────────────────┤
│ 方案 2: CUPED 引入前置 30 天历史消费协变量 (CUPED Variance Reduction)   │
│ • 利用 VIP 用户稳定的历史消费惯性 (ρ ≈ 0.85~0.90)                      │
│ • 方差削减至 28%, 等效将小样本层的有效样本量瞬间放大 3.5 倍以上        │
├────────────────────────────────────────────────────────────────────────┤
│ 方案 3: 非参数精确置换检验与后验超越概率 (Exact Permutation Test)       │
│ • 摆脱大样本正态性依赖，直接计算后验概率 P(θ_T > θ_C | Data) > 0.90   │
└────────────────────────────────────────────────────────────────────────┘
```
