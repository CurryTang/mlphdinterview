## 1 · 市场架构与流动性生态

### 一级市场与二级市场

金融资产的生命周期起始于资本形成，并依靠持续的换手实现价格发现。

```text
一级市场 (Primary market)
核心功能：资本形成与实体融资
参与者行为：企业与政府发行新证券，资金直接流向发行方
典型场景：IPO、定增、发债

二级市场 (Secondary market)
核心功能：存量流通与价格发现
参与者行为：投资者之间换手交易，发行人不直接参与
典型场景：股票买卖、衍生品平仓
```

二级市场为投资者提供了即时变现的通道。流动性溢价是资产估值的重要组成部分。

### 交易场所的组织形式

市场按照标准化程度与清算机制分为三类：

| 组织形式 | 核心特征 | 典型标的 |
|---|---|---|
| 场内交易所 (Exchange) | 合约高度标准化（面值、到期日统一）。具备中央清算所 (CCP)，实行每日盯市结算，消除双边违约风险。信息通过公开限价订单簿 (CLOB) 广播。 | 股票现货、期货、场内期权 |
| 场外交易 (OTC) | 买卖双方点对点协商，条款完全定制化。存在交易对手信用风险。通常通过 ISDA 协议约束。 | 利率互换 (IRS)、信用违约互换 (CDS)、外汇远期 |
| 暗池 (Dark pool) | 不公开披露挂单规模与预期价格。用于隐蔽执行大额交易，减少市场冲击成本。 | 机构大宗股票交易 |


### 限价订单簿 (CLOB) 撮合机制补充

在集中限价订单簿中，所有未成交的挂单按“价格优先、时间优先”原则排序。
- 买单 (Bid) 按照价格从高到低排列，卖单 (Ask) 按照价格从低到高排列。

- 最高买价与最低卖价之间的差额即为买卖价差 (Bid-Ask Spread)。

- 市价单 (Market Order) 会立即以最优价格撮合成交，提取流动性，并产生滑点成本。

- 限价单 (Limit Order) 则停留在订单簿中提供流动性，等待被他人市价单吃掉。

做市商持续挂出限价单提供流动性，而程序化交易者和机构对冲程序则通过市价单迅速调整头寸。

### 市场参与者拆解

金融市场的流动性与价格形成由三类机构分工完成：

1. **买方 (Buy-side)**
   - 掌握出资权与决策权。
   - 包括提供长牛资金的资产所有者（养老金、主权财富基金）、追求相对基准收益的传统资管公司，以及追求绝对收益的对冲基金。
   - 对冲基金利用杠杆与多空工具剥离系统性风险，追求独立的风险溢价。

2. **卖方 (Sell-side)**
   - 提供执行通道与中介服务。
   - 投资银行部协助一级市场定价与分销。
   - 主经纪商 (Prime brokerage) 业务提供保证金杠杆、融券票源池、清算托管与直接市场接入 (DMA)。

3. **做市商 (Market maker)**
   - 核心模式：不进行方向性投机。通过在订单簿两端同时报出买价 (Bid) 与卖价 (Ask)，赚取买卖价差。
   - 核心风险：逆向选择（与知情交易者做对手盘时的定价滞后）与库存风险（非均衡单边头寸暴露）。
   - 做市算法需要在微秒级别动态调整双边报价，并通过高度相关的衍生品工具转移库存敞口。

## 2 · 现货资产：股票、固定收益与商品

在多资产类别中，不同资产反映了不同的经济宏观维度与现金流特征。

### 股票与融券做空机制

普通股代表对公司资产与未来自由现金流的剩余索取权。

在破产清算场景下，资本结构的偿付顺序严格如下：

```text
优先抵押债券
-> 普通无担保债券
-> 次级债务
-> 优先股
-> 普通股
```

普通股股东处于偿付链条末端，承担最高风险，因此长期享有股权风险溢价。

融券做空 (Short selling) 是量化多空策略的基础。
- 借券成本：做空前需向主经纪商借入底层股票。流动性充足的蓝筹股借券费率极低；流通盘小或被密集做空的股票成为难借入股票 (Hard-to-borrow)，借券年化成本可能飙升至极高水平。

- 轧空风险 (Short squeeze)：若标的股票价格剧烈上涨，做空账户的维持保证金将被击穿。券商的强制平仓将转化为被动市价买盘，导致价格呈指数级正反馈飙升。


### 债券与固定收益

债券利率构成了金融资产定价的引力中心。任何资产的公允价值均为未来预期现金流的贴现和：

$$P = \sum_{t=1}^{T} \frac{CF_t}{(1 + r)^t}$$

贴现率 $r$ 的上升会导致远期现金流现值大幅缩水。

- **收益率曲线 (Yield curve)**：连接不同期限国债收益率的曲线。常态下向上倾斜，反映期限溢价。若短期收益率高于长期，形成倒挂，常被视为货币紧缩与周期衰退的前置信号。

- **信用利差 (Credit spread)**：企业债收益率减去同期限无风险国债收益率。利差反映了发行主体违约概率的市场定价。流动性紧缩时，信用利差会剧烈走阔。

- **久期 (Duration)**：衡量债券价格对利率平行移动的线性敏感度。久期越长，资产对贴现率变动越敏感。长久期资产在加息周期中面临巨大的估值重估压力。

- **凸性 (Convexity)**：价格与收益率关系的二阶导数。当利率下降时，债券价格加速上涨；利率上升时，价格减速下跌。凸性为债券多头提供了非线性的保护垫。


### ETF 与实物套利机制

ETF 通过一级市场申赎机制维持市价与底层净值 (NAV) 的高度拟合。授权参与商 (AP) 承担了跨市场套利职能。

| 市场状态 | 授权参与商套利路径 | 市场价格反馈 |
|---|---|---|
| 二级市场溢价 | 在股票市场买入底层成份股，向基金公司实物申购 ETF 份额，在二级市场卖出 ETF。 | ETF 供给增加，市价向净值回落。 |
| 二级市场折价 | 在二级市场低价买入 ETF 份额，向基金公司赎回底层成份股，在股票市场抛售。 | ETF 供给减少，市价向净值回归。 |

### 外汇与大宗商品

外汇由全球银行间网络 24 小时连续报价，是流动性最充沛的资产类别。
- 息差交易 (Carry trade)：融入低息货币，买入高息货币资产赚取利差。该策略在宏观震荡期容易触发平仓踩踏，导致融资货币迅速升值，抹平前期累积的利息收益。


大宗商品定价受现货供需与储运成本约束。
- 期货升水 (Contango)：远期价格高于近端价格。通常源于现货过剩，买方需补偿卖方的仓储与保险成本。

- 现货溢价 (Backwardation)：近端价格高于远期价格。源于现货极度短缺，实体产业愿支付极高溢价获取现货（便利收益）。

## 3 · 自动做市商 (AMM) 基础

去中心化金融受限于吞吐量与计算成本，通常采用流动性池与自动化函数替代订单簿。

### 恒定乘积做市商 (CPMM)

资金池维持两种代币存量乘积的恒定：

$$x \cdot y = k$$

当交易者试图用 $\Delta x$ 个代币 $X$ 兑换代币 $Y$ 时，资金池在交易后必须满足：

$$(x + \Delta x)(y - \Delta y) = k$$

解得可兑换的 $Y$ 数量：

$$\Delta y = \frac{y \Delta x}{x + \Delta x}$$

在此曲线下，单笔交易规模 $\Delta x$ 相对于资金池深度 $x$ 越大，边际成交价格偏离越严重。这种机制自然形成了非线性的价格滑点。

### 无常损失 (Impermanent loss)

流动性提供者 (LP) 承担了资产比例被动调整的结构性成本。当市场外部价格发生变化，套利者会从池中抽走升值资产，留下贬值资产。
设两种资产初始价格相等，随后相对价格发生变化。相比于期初静态持有资产，LP 的资金变化率可推导为：

$$\text{IL}(k) = \frac{2\sqrt{k}}{1+k} - 1 \le 0$$

此处 $k$ 为外部价格变化的乘数。无论价格向上还是向下偏离，$\text{IL}$ 始终为负。这种收益特征等价于在传统金融中做空跨式期权（Short Straddle）：通过收取交易手续费，承担标的资产大幅波动的负 Gamma 凸性损失。

## 4 · 衍生品定价与对冲体系

衍生品的核心经济功能是剥离资产风险，实现风险在套期保值者与风险承担者之间的精准转移。

### 远期与期货定价

| 维度 | 远期合约 (Forwards) | 期货合约 (Futures) |
|---|---|---|
| 交易与定制 | 场外交易，期限与规模灵活定制 | 交易所挂牌，规格严格标准化 |
| 信用风险 | 存在双边违约风险 | 清算所作为中央对手方，无对手信用风险 |
| 结算流程 | 到期日一次性结算现金或现货 | 缴纳初始保证金，每日盯市结算浮盈浮亏 |

期货价格的决定依赖于持有成本模型 (Cost of carry)。
假设现货价格为 $S_0$，无风险利率为 $r$，标的资产连续红利率为 $q$，距离交割时间为 $T$。为避免无风险套利，期货理论价格必须满足：

$$F = S_0 e^{(r - q)T}$$

若市场挂牌期货价格高于此理论值，量化套利机构将执行期现套利 (Cash-and-carry arbitrage)：融入资金买入现货，同时卖出期货合约。到期交割现货偿还本息，锁定无风险价差。这股套利力量会迅速将市价压回理论值。

### 互换合约 (Swaps)

互换合约允许对等机构交换不同属性的现金流，名义本金规模极其庞大。

- **利率互换 (IRS)**：双方在同一笔名义本金上，交换固定利率与浮动利率的现金流。这广泛用于资产负债表的久期管理与利率风险对冲，从头到尾不交换本金。

- **信用违约互换 (CDS)**：针对特定债务主体违约风险的衍生保险合约。买方定期支付保费 (Spread)，若发生违约，卖方需按面值补偿债券损失。2008 年金融危机中，由于允许无底层债务敞口的机构投机性买入 CDS，违约爆发时的兑付链条直接导致了系统性的流动性枯竭。


### 期权与风险不对称性

期权解构了线性的权利与义务。买方支付权利金 (Premium)，获得行权权利且最大亏损受限；卖方收取权利金，承担无条件的履约义务与敞口风险。

期权价值的解剖结构：

$$\text{期权价格} = \text{内在价值} + \text{时间价值}$$

- 内在价值 (Intrinsic value)：若立即执行期权可获取的理论收益。

- 时间价值 (Time value)：期权价格中超出内在价值的部分，反映了到期前资产继续波动带来更有利结果的期望。在现货价刚好等于行权价时（平值状态），不确定性最高，时间价值达到绝对峰值。


**看涨-看跌平价定理 (Put-call parity)**
对于同一标的资产、相同行权价 $K$ 与到期时间 $T$ 的欧式期权，必须严格满足静态复制等式：

$$C - P = S - K e^{-rT}$$

买入看涨并卖出看跌期权，其组合损益完全等价于持有现货并借入现值对应的资金。如果市场报价偏离该等式，做市商会立即执行无风险转换或反转套利。

**提前行权逻辑**
对于无红利支付的底层股票，美式看涨期权不应被提前行权。因为提前行权仅能获取内在价值，而直接在二级市场平仓卖出可以额外收回剩余的时间价值，且推迟支付行权金可节省利息成本。

## 5 · BSM 模型与希腊字母

Black-Scholes-Merton 框架论证了期权定价与主观对方向预测的无关性，将定价过程转化为客观的复制成本测算。

### 动态 Delta 复制

通过持有期权并利用标的现货进行反向对冲，可以使组合在极短时间间隔内对底层资产的微小波动免疫。当组合实现了完全无方向性风险，其预期收益必然等于无风险利率。
由此推导的 BSM 偏微分方程成为了衍生品估值的解析基准。定价模型中的关键输入参数包含了标的资产现价、行权价、无风险利率、到期时间，以及预期波动率。

### 隐含波动率 (Implied volatility)

由于未来真实的波动率不可观测，交易员将市场实际成交的期权市价反向代入 BSM 公式，求解出的波动率被称为隐含波动率 (IV)。它代表了市场对未来资产波动的共识定价。

- **波动率偏斜 (Volatility skew)**：在股票指数期权中，低行权价的虚值看跌期权隐含波动率显著高于平值期权。这反映了市场参与者对系统性暴跌尾部风险的结构性对冲需求，以及股价下跌时公司财务杠杆被动升高的杠杆效应。


### 希腊字母风险矩阵

量化做市与投资组合管理使用希腊字母度量非线性敞口。

| 风险维度 | 数学定义 | 交易释义 |
|---|---|---|
| **Delta ($\Delta$)** | $\frac{\partial V}{\partial S}$ | 期权价格对底层资产价格的线性敏感度。代表等效现货头寸。 |
| **Gamma ($\Gamma$)** | $\frac{\partial^2 V}{\partial S^2}$ | Delta 对底层资产价格变动的敏感度（曲率）。平值期权 Gamma 最大。 |
| **Theta ($\Theta$)** | $\frac{\partial V}{\partial t}$ | 随时间流逝，期权价值的衰减速率。多头付出 Theta，空头收取 Theta。 |
| **Vega ($\nu$)** | $\frac{\partial V}{\partial \sigma}$ | 期权价格对隐含波动率变动的敏感度。 |
| **Rho ($\rho$)** | $\frac{\partial V}{\partial r}$ | 期权价格对无风险利率变动的敏感度。 |

做多 Gamma（持有期权多头）能够在标的资产剧烈震荡中获利，但这必须以每天支付 Theta 为代价。这体现了期权定价中的能量守恒定律：
$$\Theta + \frac{1}{2}\sigma^2 S^2 \Gamma \approx 0$$
若实际实现的波动率不及隐含波动率的定价，多头将面临系统性净亏损。

## 6 · 投资组合与收益解构

现代投资组合理论利用资产间的非完全相关性优化风险收益比。

### 分散化与资本资产定价模型

结合多个相关系数 $\rho < 1$ 的资产，可在不降低预期收益的前提下缩减组合总方差。
资本资产定价模型 (CAPM) 将投资组合的超额收益解构为两个正交部分：

$$R_p = R_f + \beta (R_m - R_f) + \alpha$$

- **Beta ($\beta$)**：资产相对大盘波动的系统性风险敞口。

- **Alpha ($\alpha$)**：资产自身产生的、与系统性风险无关的特异性超额收益。剥离 Beta，捕获纯净稳健的 Alpha 是量化策略的核心目标。


### 经典资产配置流派与风险贡献

工业界演化出了数种代表性的资产配置哲学：

| 流派名称 | 资产配比模式 | 底层逻辑 |
|---|---|---|
| 经典 60/40 组合 | 60% 股票 + 40% 国债 | 股票赚取经济增长收益，债券在经济下行与衰退期提供抗跌缓冲。 |
| 风险平价 (Risk Parity) | 引入杠杆动态配比股、债与商品 | 抛弃固定金额配比，确保各类别资产对组合总方差的风险贡献严格均等。 |
| 耶鲁模式 (Endowment) | 重配私募股权、房地产与绝对收益工具 | 牺牲短期流动性，以捕获长期非流动性资产的超额风险溢价。 |

在传统的 60/40 组合中，由于股票的波动率（约 16%）远高于国债（约 5%），超过 90% 的组合波动实际上完全由股票端贡献。资金分配比例绝不等于实际风险承担比例。

## 7 · 量化金融分析工具

以下 Python 脚本用于期权定价分析与组合风险拆解。

### 期权解析定价器与希腊字母计算

利用 BSM 解析解计算欧式期权价格与核心敏感度指标。

```python
import math
from typing import Dict, Literal

class BSMAnalytics:
    """期权定价与希腊字母分析工具"""

    @staticmethod
    def _phi(x: float) -> float:
        """标准正态分布概率密度函数"""
        return math.exp(-0.5 * x * x) / math.sqrt(2.0 * math.pi)

    @staticmethod
    def _cdf(x: float) -> float:
        """标准正态分布累积分布函数"""
        return 0.5 * (1.0 + math.erf(x / math.sqrt(2.0)))

    @classmethod
    def price_and_greeks(
        cls,
        spot: float,
        strike: float,
        time_to_maturity: float,
        risk_free_rate: float,
        volatility: float,
        option_type: Literal["call", "put"] = "call",
    ) -> Dict[str, float]:
        """计算期权理论价格与各项希腊字母"""
        s, k, t, r, sigma = spot, strike, time_to_maturity, risk_free_rate, volatility

        if t <= 0:
            payoff = max(s - k, 0.0) if option_type == "call" else max(k - s, 0.0)
            return {"price": payoff, "delta": 0.0, "gamma": 0.0, "theta": 0.0, "vega": 0.0}

        sqrt_t = math.sqrt(t)
        d1 = (math.log(s / k) + (r + 0.5 * sigma**2) * t) / (sigma * sqrt_t)
        d2 = d1 - sigma * sqrt_t

        n_d1 = cls._phi(d1)
        cdf_d1 = cls._cdf(d1)
        cdf_d2 = cls._cdf(d2)

        df = math.exp(-r * t)

        if option_type == "call":
            price = s * cdf_d1 - k * df * cdf_d2
            delta = cdf_d1
            theta = -(s * n_d1 * sigma) / (2.0 * sqrt_t) - r * k * df * cdf_d2
        else:
            price = k * df * cls._cdf(-d2) - s * cls._cdf(-d1)
            delta = cdf_d1 - 1.0
            theta = -(s * n_d1 * sigma) / (2.0 * sqrt_t) + r * k * df * cls._cdf(-d2)

        gamma = n_d1 / (s * sigma * sqrt_t)
        vega = s * sqrt_t * n_d1

        return {
            "price": round(price, 4),
            "delta": round(delta, 4),
            "gamma": round(gamma, 4),
            "theta_daily": round(theta / 365.0, 4),
            "vega_1pct": round(vega / 100.0, 4)
        }

if __name__ == "__main__":
    res = BSMAnalytics.price_and_greeks(
        spot=100.0, strike=100.0, time_to_maturity=1.0, 
        risk_free_rate=0.05, volatility=0.20, option_type="call"
    )
    for key, value in res.items():
        print(f"  {key:18s}: {value}")
```

### 投资组合风险真实贡献测算

基于欧拉定理分解各大类资产对组合总波动率的边际风险贡献。

```python
def portfolio_risk_breakdown(
    weight_stock: float,
    weight_bond: float,
    vol_stock: float = 0.18,
    vol_bond: float = 0.06,
    corr: float = 0.0,
):
    """计算组合整体方差与资产的真实风险贡献占比"""
    w_s, w_b = weight_stock, weight_bond
    sigma_s, sigma_b = vol_stock, vol_bond

    # 组合总方差与波动率
    variance_total = (
        (w_s * sigma_s) ** 2
        + (w_b * sigma_b) ** 2
        + 2 * w_s * w_b * sigma_s * sigma_b * corr
    )
    vol_total = variance_total**0.5

    # 边际风险贡献
    mrc_stock = (w_s * sigma_s**2 + w_b * sigma_s * sigma_b * corr) / vol_total
    mrc_bond = (w_b * sigma_b**2 + w_s * sigma_s * sigma_b * corr) / vol_total

    # 总风险贡献
    trc_stock = w_s * mrc_stock
    trc_bond = w_b * mrc_bond

    pct_stock = (trc_stock / vol_total) * 100
    pct_bond = (trc_bond / vol_total) * 100

    print(f"资金配置比例: 股票 {w_s*100:.0f}% / 债券 {w_b*100:.0f}%")
    print(f"组合年化波动率: {vol_total*100:.2f}%")
    print(f"实际风险承受占比 -> 股票: {pct_stock:.2f}% | 债券: {pct_bond:.2f}%\n")


if __name__ == "__main__":
    print("传统 60/40 组合分析：")
    portfolio_risk_breakdown(weight_stock=0.60, weight_bond=0.40)
    
    print("风险平价组合分析：")
    portfolio_risk_breakdown(weight_stock=0.25, weight_bond=0.75)
```
