# Quant 09 · 博弈论

课程位置：[[Quant12 Brownian Motion Ito Calculus Stopping Times and Options|08 布朗运动]] → 本篇 → [[Quant14 Financial Markets Asset Classes and Portfolio Theory|10 市场]]

博弈论是分析多主体策略交互、逆向归纳与信息不对称决策的数学理论。

## 1 · 核心概念与均衡

| 概念 | 定义 |
|---|---|
| 标准式博弈 | 由局中人、纯策略空间和收益函数组成，常用于静态博弈。 |
| 展开式博弈 | 以博弈树表示，包含决策节点、信息集和时序。 |
| 占优与劣势策略 | 若某策略对所有对手动作的收益都严格更高，为严格占优。理性人不会采用严格劣势策略。 |
| 纳什均衡 | 没有任何人有单方面改变当前策略的动力（策略互为最佳应对）。 |
| 混合策略与无差异 | 当采用混合策略时，赋予正概率的所有纯策略必须带来严格相等的期望收益。 |
| 极小极大定理 | 零和博弈中，最大化自身收益下界等价于极小化对手收益上界。这驱使了混合策略中的期望“削峰填谷”。 |
| 子博弈精炼纳什均衡 (SPE) | 策略组合在每一个子博弈中都构成纳什均衡。通常用逆向归纳法（Backward Induction）求解。 |

## 2 · 动态博弈与逆向归纳

### 海盗分金

5 个海盗（1 最凶，5 最弱）分 100 枚金币。1 先提议，需 $\ge 50\%$ 赞成票通过，否则喂鲨鱼。偏好：保命 > 金币 > 杀人。
逆向归纳：
- 剩 4、5：4 提议 `(100, 0)` 自己赞成通过。
- 剩 3、4、5：3 需 2 票。给 5 1 枚金币即可（$1 > 0$），提议 `(99, 0, 1)`。
- 剩 2、3、4、5：2 需 2 票。给 4 1 枚金币即可，提议 `(98, 0, 1, 0)`。
- 剩 1 到 5：1 需 3 票。给 3 和 5 各 1 枚金币，提议 `(96, 0, 1, 0, 1)`。

### 老虎与羊

$N$ 只完全理性的老虎和 1 只羊。老虎吃羊后变成羊。偏好：保命 > 吃羊。
- $N=1$：吃（安全）。
- $N=2$：不吃（吃后变成羊会被剩下 1 只吃掉）。
- $N=3$：吃（吃后剩下 2 只不敢吃它）。
奇偶性递归：奇数只老虎第一只必定吃羊，偶数只老虎全都不吃。

### 三方决斗

A 命中率 $1/3$，B 命中率 $2/3$，C 命中率 $1$。轮流开枪（A $\to$ B $\to$ C）。可故意朝天放枪。
两人残局 A 的胜率：
- A 先手对 B：$P_{AB} = 1/3 + (2/3)(1/3)P_{AB} \implies P_{AB} = 3/7$。
- A 先手对 C：$P_{AC} = 1/3 + (2/3) \times 0 = 1/3$。
三人都在场时，B 必打 C，C 必打 B。A 的第一枪策略：
- 打中 C：进入 B 先手的 A vs B，A 存活率 $(1 - 2/3) \times 3/7 = 1/7$。此策略总胜率 $1/3 \times 1/7 + 2/3 \times 3/7 = 1/3$。
- 打中 B：必被 C 击杀。总胜率 $2/7$。
- 朝天放枪：轮到 B 打 C。若 B 击杀 C（概率 $2/3$），A 面对 B 先手，胜率 $3/7$；若 B 击空（概率 $1/3$），C 击杀 B，A 面对 C 先手，胜率 $1/3$。A 总胜率 $(2/3)(3/7) + (1/3)(1/3) = 25/63 \approx 39.7\%$。
最优决策是第一枪朝天放枪。

## 3 · 静态与组合博弈

### 猜均值的 2/3

$N$ 人每人在 $[0, 100]$ 内选数。最接近均值 $2/3$ 的人获胜。
- 策略空间 $S_0 = [0, 100]$。均值最大为 100，目标最大为 $66.67$。大于 $66.67$ 为严格劣势策略，剔除后空间收缩为 $S_1 = [0, 66.67]$。
- 第 $k$ 轮收缩：$S_k = [0, 100 \times (2/3)^k]$。
极限为 $S_\infty = \{0\}$，唯一的纳什均衡是所有人均选 $0$。

### 拍卖与收益等价

竞标者独立私有估值 $v \sim U[0, 1]$：
- **二阶价格拍卖**：若出价 $b > v$，当次高价 $P_2 \in (v, b)$ 时净亏损 $v - P_2 < 0$；若 $b < v$，当 $P_2 \in (b, v)$ 时失去原本 $>0$ 的收益。因此诚实出价 $b(v) = v$ 是弱占优策略。
- **一阶价格拍卖**：期望利润 $E[\Pi] = (v - b) \beta(b)^{n-1}$。对 $b$ 求偏导得一阶条件 $-( \beta(b) )^{n-1} + (v-b)(n-1)\beta(b)^{n-2}\beta'(b) = 0$。代入对称均衡 $\beta(b)=v$ 求解微分方程得 $b(v) = \frac{n-1}{n} v$。
- **全支付拍卖**：期望利润 $E[\Pi] = v \beta(b)^{n-1} - b$。一阶条件求解得 $b(v) = \frac{n-1}{n} v^n$。
收益等价定理表明这三种机制下卖家的期望收益严格相等，均为 $\frac{n-1}{n+1}$。

### 公司收购

目标公司真实价值 $V \sim U[0, 100]$。收购后价值升至 $1.5V$。收购方给出一口价 $B$，目标公司在 $B \ge V$ 时接受。
由于只有 $V \le B$ 时才接受（逆向选择），收购成功条件下的真实价值期望为截断均值 $E[V \mid V \le B] = B/2$。
收购成功后的期望价值为 $1.5 \times (B/2) = 0.75B$。
期望利润为 $P(V \le B) \times (0.75B - B) = -0.25B^2 / 100 \le 0$。最优出价 $B^* = 0$。

### 硬币排线

$2n$ 枚已知面值硬币排成一行，两人轮流从两端取一枚。
奇偶位置分离：分为奇数位硬币总和 $S_{odd}$ 与偶数位硬币总和 $S_{even}$。
先手第一步取走奇数位或偶数位，可始终迫使后手面临两端同为偶数位（或奇数位）的状态，从而拿走全部目标奇偶位的硬币。先手至少能拿到 $\max(S_{odd}, S_{even}) \ge 50\%$。

### Chomp 网格与帽子校验

**Chomp**：$R \times C$ 网格，$(1, 1)$ 有毒。选一格并吃掉其右上方所有格子。吃到有毒格子者输。
偷策略反证法：假设后手有必胜策略。先手第一步只吃最右上角的一格 $(R, C)$，此时进入后手的必胜态，后手有对应的制胜步 $A$。但先手在第一步完全可以直接走 $A$ 来进入该状态。由于矛盾，先手必定有必胜策略。

**100 人红蓝帽子**：排队看前方。第 100 号（最后一人）数前面 99 人的红帽总数，报出奇偶校验位 $S_{99} \pmod 2$。
第 99 号通过全局奇偶性和眼前 98 人的帽子推算出自己颜色，存活并更新全局奇偶性。以此类推，前 99 人 $100\%$ 存活。

### 俄罗斯轮盘赌

6 孔左轮 2 发子弹。对手扣扳机为空，现在轮到你。
- **子弹相邻**：当前是 4 个空位之一。直接扣，下一发是子弹的概率为 $1/4 = 25\%$。重转概率为 $2/6 = 33.3\%$。应直接扣。
- **子弹不相邻**：4 个空位中有 2 个的下一个是子弹。直接扣概率为 $2/4 = 50\%$。重转概率为 $33.3\%$。应重转。

## 4 · 博弈模型速查

| 模型 | 特征 | 核心结论 |
|---|---|---|
| 海盗分金 / 老虎与羊 | 动态完全信息 | 逆向归纳。奇数老虎吃，偶数不吃。 |
| 三方决斗 | 状态转移 | 残局逆推。弱者弃权获最高胜率。 |
| 猜均值的 2/3 | 连续协调博弈 | 严格劣势策略迭代剔除。均衡为 0。 |
| 密封竞价拍卖 | 不完全信息博弈 | 一阶报价 $v(n-1)/n$，二阶报价 $v$。收益等价。 |
| 公司收购 | 逆向选择 | 截断条件期望 $E[V \mid V \le B]$。出价必亏。 |
| 硬币排线 / Chomp | 确定性组合博弈 | 奇偶控制；偷策略反证先手必胜。 |
| 100 人红蓝帽子 | 协作信息传递 | 尾人牺牲广播奇偶校验位。 |
